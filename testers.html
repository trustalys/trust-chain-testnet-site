Trust Chain test network

For testers

Before you start

The network usually runs, but it is a best-effort service. It may be off at any time, with no notice. Do not build anything that depends on it.

All data on the network is deleted on the first Monday of each month at 06:00 UTC, and at early resets announced on the main page. Your agents and identifiers go with it.

Whether it runs now: see the main page. Using the network means you accept its terms.

The SDK's documentation

How to use the Trust Chain SDK is explained in its documentation, in the SDK's repository. To get access, ask through www.trustalys.com, and give your GitHub user name.

The SDK itself is on npm: @trustalys/trust-chain-sdk, version 0.7.0 or later.

Connect
