Trust Chain test network

A public network for trying the Trust Chain SDK: an agent service (KERIA), three witnesses and a schema server, at addresses under test.trustalys.net. It is for testing only, and its data is deleted at each reset.

Now

Turn on JavaScript to see whether the network runs now.

The network runs only when testers need it. It may be off at any time.

Resets

At each reset, all data on the network is deleted: agents, identifiers and what the witnesses hold. The witnesses keep their identifiers.

Resets happen on the first Monday of each month at 06:00 UTC. An early reset is announced here at least 2 days before.

Terms

Using the network means you accept its terms: test use only, no personal data, no real LEIs, no promise that it runs.
