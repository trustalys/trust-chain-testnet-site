Trust Chain test network

Terms

These terms apply to every address under test.trustalys.net.

  1. The network is for testing the Trust Chain SDK only.
  2. All data is deleted at each reset: on the first Monday of each month at 06:00 UTC, and at early resets announced on the main page.
  3. Do not put personal data, real LEIs or anything of value on the network.
  4. There is no promise that the network runs at any time.
  5. The network keeps a log of requests with shortened IP addresses: the last part of each address is removed before it is written. The log is used to count visits and the countries they come from. No full IP address is kept.
  6. GitHub hosts this site and keeps its own logs, as its privacy statement says. This site sets no cookie and loads nothing from other servers.
